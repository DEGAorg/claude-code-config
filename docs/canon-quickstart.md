# Canon Quickstart

Get a prediction market strategy running in 3 steps. No coding required.

## Prerequisites

Run `/apply-core` inside any AI agent (Claude, Gemini, Codex) and select
**Canon Bootstrap**. This installs the Canon scripts globally.

You also need one of:
- **Canon TUI** (recommended) — see DEGAorg/canon-tui README
- **tmux** — `brew install tmux`

## Steps

### 1. Create a project directory

```bash
mkdir my-strategy
cd my-strategy
```

### 2. Run `/canon-init`

Open your AI agent and type:

```
/canon-init
```

This checks prerequisites, fetches the Canon commands, and writes a
`canon.sh` launcher to the project root. When it finishes, exit the agent.

### 3. Run the launcher

```bash
./canon.sh
```

This opens the Canon environment. If the Canon TUI is installed, it launches
the full TUI with conversation and live dashboard. Otherwise it falls
back to a tmux split with the agent on the left and a status dashboard
on the right.

`/canon-start` runs automatically and guides you through the full pipeline:

1. **Scaffold** — fetches agents, skills, templates, and generates project structure
2. **Strategy** — asks which strategy to use (template, market scan, or custom)
3. **Build** — the Conductor drives agents to implement the strategy
4. **Review** — automated code review, iterates until it ships
5. **Run** — launches the strategy scanner in the background

## What gets created

After the pipeline runs, your project directory contains:

```
my-strategy/
├── canon.sh              ← launcher (written by /canon-init)
├── agent-shim.sh         ← agent-agnostic helper
├── package.json          ← generated by scaffold
├── tsconfig.json         ← generated by scaffold
├── dega-core.yaml        ← success criteria
├── .canon/
│   ├── state.json        ← live dashboard state
│   ├── config.yaml       ← agent/skill mappings
│   ├── agents/           ← 6 agent personas
│   ├── skills/           ← 8 domain skills
│   └── execution/        ← runner logs and decision journal
├── src/                  ← strategy code (built by agents)
└── docs/
    └── strategy-*.md     ← strategy specification
```

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `/canon-init` says prerequisites missing | Run `/apply-core` and select Canon Bootstrap + Terminal UI |
| `./canon.sh` says neither canon nor tmux found | Install the Canon TUI (see DEGAorg/canon-tui) or `brew install tmux` |
| Scaffold fails to fetch from GitHub | Check internet connection; scaffold fetches from `raw.githubusercontent.com` |
| Build phase hangs | Check `dega-core.yaml` has a valid `check_command` for your project |
