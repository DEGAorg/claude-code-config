--- item: Convert 4 MP3 sounds to OGG using ffmpeg ---
Converted all 4 MP3 files in sounds/ to OGG format using ffmpeg with libopus codec
(not libvorbis — Homebrew ffmpeg doesn't ship libvorbis, and the native vorbis encoder
is marked experimental). Used `ffmpeg -i X.mp3 -c:a libopus -b:a 64k X.ogg`. OGG Opus
is natively supported by paplay (PulseAudio/PipeWire), which is the target use case.
Files created: unstoppable.ogg (18KB), super-mario-bros.ogg (12KB), warzone-level-up.ogg
(42KB), yeahoo.ogg (10KB). The play-sound.sh rewrite should reference .ogg for paplay
and note that these are Opus-encoded (paplay handles both Vorbis and Opus in OGG containers).

--- item: Rewrite `hooks/play-sound.sh` with platform detection, `none` disable, and volume control ---
Rewrote hooks/play-sound.sh from the macOS-only afplay script to a cross-platform
version. Platform detection uses `uname -s` with a case statement: Darwin uses afplay,
Linux tries mpv > ffplay > paplay > WSL2 PowerShell in priority order. mpv/ffplay use
MP3 files directly; paplay uses .ogg (Opus-encoded, from previous task). WSL2 detected
via `grep -qi microsoft /proc/version`, falls back to PowerShell WPF MediaPlayer.
CLAUDE_SOUND=none (or empty) exits immediately. CLAUDE_SOUND_VOLUME (0-100, default 50)
normalized per player: afplay/powershell get float 0.0-1.0 via awk, paplay gets
0-65536 via shell arithmetic, mpv/ffplay pass through directly. All playback is
backgrounded with `& disown`. No player found = silent skip. Script still needs
shellcheck/shfmt pass (next task).
