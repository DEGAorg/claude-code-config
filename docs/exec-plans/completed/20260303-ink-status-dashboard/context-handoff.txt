--- item: Create `src/log-panel.tsx` — recent log entries display ---
Created `scripts/terminal-ui/src/log-panel.tsx` (~60 lines). Exports a LogPanel
component that takes `logs: readonly LogEntry[]`. Uses Ink's `useStdout()` hook
to detect terminal height and shows the most recent N entries that fit (subtracts
8 rows for chrome: StatusBar border + MetricsPanel + padding). Each row shows
time (HH:MM:SS via toLocaleTimeString), level (color-coded: info=blue, warn=yellow,
error=red, debug=gray, padded to 5 chars), and message. Empty state shows
"No log entries yet" in dim text. Box has flexGrow=1, borderStyle="single" with
borderTop=false to connect visually to StatusBar's border above.

--- item: Create `src/metrics-panel.tsx` — key-value metrics grid ---
Created `scripts/terminal-ui/src/metrics-panel.tsx` (~60 lines). Exports a MetricsPanel
component that takes `metrics: Readonly<Record<string, unknown>>`. Renders a two-column
key-value grid inside a Box with borderStyle="single", borderTop=false (connects visually
to LogPanel above). Pairs entries side-by-side (two per row). Uses a formatValue helper
that renders null/undefined as "—" and everything else as String(value). Empty state shows
"No metrics" in dim text. Keys are bold, values are plain text. Each column has minWidth=30
for alignment.
