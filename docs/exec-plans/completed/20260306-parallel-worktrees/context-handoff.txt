--- item: Write `scripts/ralph-worktree.sh` — create worktree, run loop, cleanup ---
Created scripts/ralph-worktree.sh (118 lines, executable). The script handles the full
worktree lifecycle: prunes stale entries on startup, creates worktree at
.claude/worktrees/<slug> on branch ralph/<slug> (or reattaches if existing), copies
exec plan files into the worktree, runs ralph-loop.sh via subshell cd, then on exit
reports the branch for PR (SHIP), keeps the worktree (dirty exit), or removes worktree
and branch (clean exit with no changes). Passes shellcheck and shfmt cleanly. Note:
idempotency (reattach) and prune are already built into this script, so those plan items
may only need verification rather than new implementation.
