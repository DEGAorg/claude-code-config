--- item: Write atomic state writer in `src/write.ts` with log ring buffer ---
Created `scripts/terminal-ui/src/write.ts` with two exports: `readState(filePath)` returns
`TerminalUIState | null` (null on ENOENT), and `writeState(filePath, update)` does atomic
read-merge-rename. Added `@types/node@22.19.13` devDep for Node.js type definitions.
Key behaviors: log ring buffer appends `update.appendLogs` and slices to `LOG_BUFFER_MAX` (50);
metrics are shallow-merged (callers add keys without replacing all); `error` field uses
`"error" in update` check to distinguish absent from explicitly-null (clearing error);
atomic write uses `randomBytes` temp file in same directory + `rename`. `tsc --noEmit` passes.

--- item: Write shell helper `scripts/terminal-ui-write.sh` for bash callers ---
Created `scripts/terminal-ui-write.sh` — a bash equivalent of the TS `writeState()` function.
Uses jq for all JSON manipulation. Supports key=value CLI args: phase, status, error,
startedAt, metric.<key>=<val> (auto-detects JSON vs string), log.<level>=<msg>. Implements
same behaviors as TS writer: atomic temp+rename, log ring buffer capped at 50, shallow
metric merge, error= clears to null. Passes shellcheck and shfmt clean. Tested: fresh
create, update existing state, error clearing, ring buffer overflow (55 entries → 50 retained),
invalid log level rejection, missing args rejection.
