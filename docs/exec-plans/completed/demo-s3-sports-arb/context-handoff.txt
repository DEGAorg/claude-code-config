--- item: Create `src/strategies/sports-arb/risk.ts` ---
Created src/strategies/sports-arb/risk.ts with createRiskGuard() factory function
returning a RiskInterface implementation. Three pre-trade checks in order:
(1) daily loss limit — rejects if daily_pnl exceeds maxDailyLossPct (default 2%),
(2) position size cap — reduces size to maxPositionPct (default 5%) via modified_size
or rejects if portfolio is zero, (3) resolution guard — rejects if market resolves
within resolutionGuardSecs (default 60s) using an injected getResolutionDate lookup.
Circuit breaker (onCircuitBreaker) sets a halted flag that rejects all subsequent
trades. getExposure() computes from the last portfolio snapshot seen in preTradeCheck.
RiskConfig allows overriding all thresholds. tsc --noEmit and oxlint both clean.
