--- item: Create `scripts/log-server.py` ---
Created scripts/log-server.py as a uv inline-script daemon (PEP 723 format, requires-python >=3.13,
depends on google-cloud-logging). The server binds a Unix socket at ~/.claude/logs/log.sock, reads
newline-delimited JSON, writes to ~/.claude/logs/ralph/YYYY-MM-DD.jsonl, and spawns a daemon thread
per event for optional async GCP Cloud Logging forwarding. GCP credentials are loaded from
~/.claude/gcp-sa.json (or $GOOGLE_APPLICATION_CREDENTIALS); startup warning is emitted and server
continues in local-only mode if absent. SIGTERM handler cleans up socket and PID file. All public
APIs have Google-style docstrings; BLE001 noqa comments mark the two intentional broad-exception
catches at GCP boundaries.
---

--- item: Create `scripts/log-client.sh` ---
Created scripts/log-client.sh as a sourceable bash helper. Sets LOG_AVAILABLE=0/1 at source time
based on socat availability. Exports log_event(EVENT_NAME [PAYLOAD_JSON]) which builds a JSON
envelope with ts (UTC ISO-8601), session ($SESSION_ID), script (basename of BASH_SOURCE[1]), event,
and payload, then pipes it to socat -u STDIN UNIX-CONNECT:~/.claude/logs/log.sock with
2>/dev/null || true for silent fallback. The pipe uses shfmt-preferred style (| at end of line).
Passes both shellcheck and shfmt -d clean. No changes to log-server.py.

--- item: Update `scripts/ralph-loop.sh` — source client, emit events ---

--arg to avoid shell escaping issues. shellcheck source directive added for log-client.sh.
