fetchOrderBook(tokenId). Both are thin wrappers over the pmxtjs Polymarket class.

--- item: Create `scripts/verify-connections.ts` ---
Created scripts/verify-connections.ts as a smoke test that calls both API clients.
Polymarket: calls fetchMarketPrice with a well-known condition ID, prints YES/NO
prices. Sportsbook: calls fetchOdds("basketball_nba"), prints first event with
moneyline odds from the first bookmaker. Each check is wrapped in try/catch and
returns boolean success. A process.on("uncaughtException") handler was added because
pmxtjs spawns a child process (pmxt-ensure-server) that can emit unhandled 'error'
